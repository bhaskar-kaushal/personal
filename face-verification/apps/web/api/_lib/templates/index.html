face-verification demo

Demo only. This is a public, unauthenticated demo of an offline facial identity verification pipeline running a compact model pack (not the CLI's higher-accuracy default). Anyone can enroll or search this gallery. Do not upload real photos of real people — use synthetic or sample faces only. The gallery is wiped daily and offers no privacy guarantees. Not for production identity verification.

Enroll

Bulk-enrolls a person from up to 5 photos (1:N-friendly gallery).
